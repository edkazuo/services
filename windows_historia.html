História da Computação · Windows 1.0 → XP

Dezesseis anos até o Windows se encontrar

De uma interface que nem sobrepunha janela até um sistema operacional único, estável, usado por décadas — foram 16 anos entre o primeiro Windows (1985) e o XP (2001), que unificou as duas linhagens que vieram a coexistir pelo caminho: a de consumidor (9x, herdeira direta do Windows original) e a corporativa (NT, nascida à parte em 1993).

A linha do tempo

Onze versões, duas famílias, um encontro

1985
Windows 1.0
Interface gráfica rodando sobre MS-DOS — mas as janelas só podiam ser lado a lado (tiled), nunca sobrepostas, por receio de disputa legal com a Apple sobre o Macintosh.
1990
Windows 3.0
A primeira versão que realmente vendeu — memória virtual, modo 386 Enhanced, Program Manager e File Manager. O Windows deixou de ser curiosidade e virou produto.
1992
Windows 3.1
Fontes TrueType, drag and drop, OLE — e o fim do modo real do processador. Estabilidade suficiente para virar padrão de escritório no mundo inteiro.
1993
Windows for Workgroups 3.11
Rede ponto a ponto embutida e acesso a arquivo de 32 bits (VFAT) — a versão que colocou o Windows dentro de escritório em rede, não só na máquina isolada.
1993
Windows NT 3.1
O nascimento da outra linhagem: primeiro Windows NT, kernel próprio sem dependência de DOS, 32 bits nativo, multitarefa preemptiva de verdade — pensado para estação de trabalho e servidor, não para o consumidor doméstico. A numeração "3.1" era só marketing, pra parecer familiar a quem já usava o Windows 3.1 de consumidor.
1994
Windows NT 3.5
Refinamento de performance e compatibilidade de rede sobre a base do NT 3.1 — ainda restrito a workstation e servidor corporativo, sem qualquer ambição de chegar ao desktop doméstico.
1995
Windows NT 3.51
A linhagem corporativa seguia caminho próprio — kernel independente do DOS, multitarefa preemptiva de verdade, pensado para servidor e estação de trabalho, não para o consumidor doméstico.
1995
Windows 95
Menu Iniciar, barra de tarefas, Plug and Play, nome de arquivo longo, TCP/IP integrado — híbrido de 16/32 bits que definiu visualmente o que "usar um computador" significava pelos quinze anos seguintes.
Nota pessoal: testei a versão beta do 95 nesse mesmo ano — na mesma época em que configurava Slackware na unha, sem Plug and Play nenhum, na outra ponta do espectro técnico.
1996
Windows NT 4.0
Pegou a interface do 95 e colocou sobre o kernel NT — a versão que fez estação de trabalho corporativa parecer tão amigável quanto a de casa, sem abrir mão da estabilidade de servidor.
Nota pessoal: anos depois, já com o screensaver "Matrix" popularizado pelo filme (1999) rodando em servidores NT 4.0/2000, virou hábito usá-lo como monitor de desempenho improvisado: se os caracteres caíam devagar, a CPU estava sobrecarregada. Décadas antes de qualquer dashboard de observability existir.
1999
Windows 98 SE
Internet Explorer integrado, suporte a USB amadurecido, compartilhamento de conexão — ainda a linhagem de consumidor, ainda apoiada em DOS por baixo.
2000
Windows 2000
NT chegando ao desktop corporativo com Active Directory — enquanto a linhagem de consumidor ainda vivia em outro trilho, tecnicamente mais frágil.
2000
Windows Millennium (ME)
Último desktop de consumidor apoiado em DOS — trouxe o System Restore, mas ficou marcado como a versão mais instável da linhagem 9x, pressionando a favor da unificação que viria a seguir.
2001
Windows XP
O encontro: kernel NT para todo mundo, consumidor e empresa, na mesma base. Suporte oficial durou até 2014 — treze anos depois do lançamento.
Por que isso importa tecnicamente

Duas famílias, dois motivos de existir

Da metade dos anos 90 até 2001, a Microsoft manteve duas linhas de desenvolvimento simultâneas, cada uma resolvendo um problema diferente.

Linhagem 9x (3.1 → 95 → 98 → ME)

Apoiada em MS-DOS por baixo, priorizava compatibilidade com hardware de consumidor e software legado — o preço disso era menos estabilidade e nenhuma proteção real de memória entre processos.

Linhagem NT (3.1 → 3.5 → 3.51 → 4.0 → 2000)

Kernel próprio, sem dependência de DOS, com multitarefa preemptiva e proteção de memória de verdade — construída para servidor e estação de trabalho corporativa, onde travar não era opção.

O XP não foi só "mais uma versão" — foi a decisão de que manter duas arquiteturas de kernel em paralelo não escalava mais. A partir dele, todo Windows subsequente (Vista, 7, 10, 11) descende da linhagem NT.
A história paralela

Enquanto isso, a Novell dominava a rede

Nenhuma história de servidor Windows dos anos 90 está completa sem mencionar quem, por muito tempo, era dono de fato do ambiente corporativo de rede.

Novell NetWare

Durante boa parte dos anos 80 e 90, Novell NetWare era o padrão de fato para rede local corporativa — sistema de arquivos e serviço de diretório (NDS) mais maduros que qualquer coisa que a Microsoft oferecia na época. Windows NT precisou coexistir ao lado de servidor Novell por anos, muitas vezes na mesma sala de rack, antes de conseguir migrar essa base de clientes.

A ascensão do Active Directory (Windows 2000) foi, em boa parte, resposta direta ao NDS da Novell — levou anos até a Microsoft convencer o mercado corporativo a abandonar uma infraestrutura de rede que já funcionava bem havia mais de uma década.
